# Arduino UNO Q 수질 센서

Arduino UNO Q에 수온, pH, 용존산소(DO), 탁도 센서를 연결해 수질 데이터를 측정하는 프로젝트입니다. 최종 통합 스케치는 측정값을 1초마다 한 줄의 JSON으로 출력하므로 시리얼 모니터에서 확인하거나 ROS 2 노드에서 읽어 사용할 수 있습니다.

## 측정 항목

| 항목 | 센서/모듈 | 출력값 |
| --- | --- | --- |
| 수온 | DS18B20 | `temp_c` (°C) |
| pH | 아날로그 pH 센서 | `ph` |
| 용존산소 | SEN0237-A 호환 DO 센서 | `do_mg_l` (mg/L) |
| 탁도 | Keyestudio Turbidity Sensor V1.0 | 센서 전압, 맑음도(%) 및 단계 |

아날로그 값은 UNO Q의 12비트 ADC(0~4095)와 3.3V 기준 전압을 사용합니다. 각 채널에서 40개 샘플을 읽고 최댓값과 최솟값을 하나씩 제외한 평균을 사용합니다.

## 배선

최종 통합 스케치 [`sensor_check/sensor_for_ros.ino`](sensor_check/sensor_for_ros.ino)의 핀 설정은 다음과 같습니다.

| 센서 신호 | UNO Q 핀 | 비고 |
| --- | --- | --- |
| DS18B20 DATA | D4 | DATA와 전원 사이에 일반적으로 4.7kΩ 풀업 저항 사용 |
| pH 모듈 A/PO | A1 | 3.3V ADC 입력 범위를 넘지 않도록 확인 |
| DO 모듈 DO | A5 | 아날로그 출력 |
| 탁도 센서 AO | A0 | 10kΩ/20kΩ 전압 분배기를 거쳐 연결 |

모든 모듈과 UNO Q의 GND를 공통으로 연결해야 합니다.

탁도 센서는 코드에 아래 전압 분배기 비율(`1.5`)이 반영되어 있습니다.

```text
탁도 센서 AO ── 10kΩ ──┬── A0
                         |
                       20kΩ
                         |
                        GND
```

이 구성에서 A0에 들어오는 전압은 센서 AO 전압의 약 2/3입니다. 저항값이나 연결 방식을 바꾸면 `TURBIDITY_DIVIDER_RATIO`도 실제 비율에 맞게 수정해야 합니다. 3.3V를 넘는 신호를 아날로그 핀에 직접 입력하지 마세요.

> 개별 테스트 스케치 중에는 예전 핀 설정을 사용하는 파일도 있습니다. 통합 측정 시에는 위 표와 `sensor_for_ros.ino`의 정의를 기준으로 연결하세요.

## 준비 및 실행

1. Arduino IDE에서 UNO Q 보드 지원 패키지를 설치하고 보드와 포트를 선택합니다.
2. 라이브러리 관리자에서 `OneWire` 라이브러리를 설치합니다.
3. 센서를 연결한 뒤 `sensor_check/sensor_for_ros.ino`를 엽니다.
4. 아래의 캘리브레이션 절차로 각 센서의 상수를 자신의 측정값으로 변경합니다.
5. 스케치를 업로드하고 시리얼 모니터를 **115200 baud**로 엽니다.

정상 출력 예시는 다음과 같습니다.

```json
{"ms":12345,"temp_c":25.42,"ph":7.03,"do_mg_l":8.21,"turbidity_voltage_v":4.765,"clarity_pct":99.0,"clarity_level":"very_clear"}
```

온도 센서가 없거나 읽기에 실패하면 온도뿐 아니라 온도 보정을 사용하는 pH와 DO 값도 `null`이 될 수 있습니다.

## 캘리브레이션

현재 코드의 보정 상수는 기존 센서로 측정한 예시값입니다. 전극, 보드, 전원, 배선이 바뀌면 값도 달라지므로 실제 사용할 장비로 다시 보정해야 합니다. 보정 중에는 실제 측정 때와 같은 전원 및 배선을 사용하고, 값이 충분히 안정된 뒤 여러 번 읽은 평균을 기록하세요.

### 1. 수온 확인

pH와 DO는 수온을 이용해 보정되므로 수온 센서부터 확인합니다.

1. DS18B20을 연결하고 [`sensor_check/수온측정.ino`](sensor_check/수온측정.ino)를 업로드합니다.
2. 시리얼 모니터를 115200 baud로 엽니다.
3. `DS18B20 온도센서 발견` 메시지와 수온이 정상적으로 출력되는지 확인합니다.
4. 기준 온도계가 있다면 같은 물에 넣고 비교합니다. 큰 차이가 지속되면 배선, 풀업 저항, 센서 방수 상태를 먼저 확인합니다.

### 2. pH 2점 보정

pH 7과 pH 4 표준 완충용액을 이용합니다. 완충용액의 실제 pH는 온도에 따라 달라질 수 있으므로 제품 표에 표시된 현재 온도의 값을 사용하면 더 정확합니다.

1. 전극을 증류수로 가볍게 헹구고 물기를 털어 냅니다. 전극을 문지르지 마세요.
2. [`sensor_check/ph_calibration.ino`](sensor_check/ph_calibration.ino)의 `BUFFER_PH`를 현재 온도에서의 pH 7 완충용액 값으로 설정합니다.
3. 스케치를 업로드하고 전극을 pH 7 용액에 넣습니다.
4. 전극과 용액 온도가 안정될 때까지 기다린 뒤 출력되는 `Voltage`의 안정 구간 평균을 `PH7_VOLTAGE`로 기록합니다.
5. 전극을 다시 헹군 뒤 `BUFFER_PH`를 pH 4 완충용액의 실제 값으로 변경하고 같은 과정을 반복해 `PH4_VOLTAGE`를 기록합니다.
6. 보정할 때의 평균 수온을 `PH_CALIBRATION_T`로 기록합니다.
7. `sensor_for_ros.ino`에서 다음 값을 교체합니다.

```cpp
#define PH7_BUFFER_VALUE 7.00   // 실제 pH 7 용액 값
#define PH4_BUFFER_VALUE 4.00   // 실제 pH 4 용액 값
#define PH7_VOLTAGE 1.142       // pH 7에서 측정한 전압(V)
#define PH4_VOLTAGE 0.888       // pH 4에서 측정한 전압(V)
#define PH_CALIBRATION_T 25.47  // 보정 당시 수온(°C)
```

마지막으로 pH 7 용액을 다시 측정해 결과가 기준값에 가깝게 돌아오는지 확인합니다. `ph_calibration.ino`가 함께 출력하는 `필요한 OFFSET`은 단일점 공식용 참고값이며, 현재 통합 스케치의 2점 보정에는 **두 전압값**을 사용합니다.

### 3. DO 공기 포화 보정

DO 센서는 젖은 프로브를 공기 중에 두고 100% 공기 포화점을 잡는 방식으로 보정합니다.

1. DO 프로브의 멤브레인, 내부 용액, 기포 여부를 센서 설명서에 따라 점검합니다.
2. 프로브를 물에 충분히 적신 뒤 물방울만 가볍게 제거합니다. 멤브레인은 마르지 않아야 합니다.
3. [`sensor_check/do_calibration.ino`](sensor_check/do_calibration.ino)를 업로드하고 시리얼 모니터를 115200 baud로 엽니다.
4. 젖은 프로브를 직사광선과 바람을 피해 공기 중에 두고 전압이 안정될 때까지 기다립니다.
5. 안정 구간의 `Saturation Voltage` 평균(mV)을 기록합니다. 동시에 DS18B20으로 보정 당시의 온도도 기록합니다.
6. `sensor_for_ros.ino`의 값을 교체합니다.

```cpp
#define DO_CAL_V 1505.0  // 공기 포화 상태에서 측정한 평균 전압(mV)
#define DO_CAL_T 25.4    // 보정 당시 온도(°C)
```

보정 후 공기와 충분히 접촉해 포화된 물에서 측정값이 해당 수온의 예상 포화 DO와 비슷한지 확인합니다. 이 코드는 0~40°C 범위의 포화 DO 표를 사용하며, 염분과 기압의 영향은 별도로 보정하지 않습니다.

### 4. 탁도 2점 보정

현재 탁도 결과는 NTU가 아니라, 두 기준 시료 사이를 선형 변환한 상대적인 **맑음도**입니다. 정제수를 100%, 프로젝트에서 정한 매우 탁한 기준 시료를 0%로 둡니다.

1. 센서 표면을 세척하고 기포가 붙지 않도록 정제수에 넣습니다.
2. 통합 스케치 또는 [`sensor_check/탁도센서측정.ino`](sensor_check/탁도센서측정.ino)를 실행합니다.
3. 센서 위치와 주변광을 고정하고 값이 안정되면 `센서 전압`의 평균을 기록합니다.
4. 같은 용기와 센서 위치에서 매우 탁한 기준 시료를 측정하고 평균 전압을 기록합니다. 시료가 가라앉으면 측정 전 매번 같은 방식으로 섞습니다.
5. `sensor_for_ros.ino`에서 두 값을 교체합니다.

```cpp
#define CLEAR_WATER_VOLTAGE 4.810  // 정제수의 센서 AO 전압(V)
#define VERY_TURBID_VOLTAGE 0.140  // 매우 탁한 기준 시료 전압(V)
```

출력 단계는 `very_clear`(80% 이상), `clear`(60% 이상), `normal`(40% 이상), `turbid`(20% 이상), `very_turbid`(20% 미만)입니다.

정량 NTU가 필요하면 0 NTU와 임의의 탁한 물만으로는 부족합니다. 인증된 여러 NTU 표준액을 사용해 측정 범위 전체의 보정 곡선을 별도로 만들어야 합니다. `탁도센서캘리브.ino`는 10비트/5V ADC를 가정한 이전 실험용 코드이므로 UNO Q 통합 스케치의 보정값을 얻을 때는 사용하지 않는 것을 권장합니다.

## 스케치 구성

| 파일 | 용도 |
| --- | --- |
| `sensor_for_ros.ino` | 수온, pH, DO, 탁도 통합 측정 및 JSON 출력 |
| `셋다측정.ino` | 수온, pH, DO를 사람이 읽기 쉬운 형식으로 출력 |
| `수온측정.ino` | DS18B20 단독 점검 |
| `ph_calibration.ino` | pH 완충용액의 ADC/전압 측정 |
| `do_calibration.ino` | DO 공기 포화 전압 측정 |
| `탁도센서측정.ino` | 탁도 센서 전압과 맑음도 단독 측정 |
| `탁도센서캘리브.ino` | 이전 10비트/5V 환경의 실험용 NTU 변환 코드 |
| `water_temperature_sensor.ino` | `DS18B20` 라이브러리를 사용하는 별도 온도 예제 |

## 문제 해결

- **모든 아날로그 값이 0 또는 최댓값으로 고정됨**: GND 공통 연결, 신호 핀, 전압 분배기와 센서 전원을 확인합니다.
- **DS18B20을 찾지 못함**: DATA 핀 번호와 풀업 저항을 확인합니다. 단독 스케치는 D2, 통합 스케치는 D4를 사용합니다.
- **pH 또는 DO가 `null`임**: 수온 측정이 정상인지, 두 pH 보정 전압이 서로 다른지, `DO_CAL_V`가 0보다 큰지 확인합니다.
- **값이 크게 흔들림**: 센서가 안정될 시간을 주고, 기포와 주변광을 제거하며, 펌프·모터와 센서 전원을 분리하거나 노이즈 대책을 적용합니다.
- **탁도 전압이 예상과 다름**: 출력에 표시되는 값은 전압 분배기 비율을 복원한 센서 AO 전압입니다. 실제 저항값과 `TURBIDITY_DIVIDER_RATIO`가 일치하는지 확인합니다.

## 주의사항

이 프로젝트의 출력은 실험 및 모니터링용입니다. 음용 적합성, 양식 생물의 안전 또는 법적 수질 판정에는 보정된 전문 계측기와 공인 시험법을 함께 사용하세요. pH와 DO 전극은 제조사가 지정한 보관액, 멤브레인 및 유지보수 절차를 따라 관리해야 합니다.
